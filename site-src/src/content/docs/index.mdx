## Install

<Tabs syncKey="install">
  <TabItem label="CDN">
    ```html
    <script
      type="module"
      src="https://cdn.jsdelivr.net/npm/zulip-embed@1/dist/zulip-embed.js"
    ></script>
    ```
  </TabItem>
  <TabItem label="npm">
    ```bash
    npm install zulip-embed
    ```
  </TabItem>
  <TabItem label="React">
    ```bash
    npm install zulip-embed-react
    ```
  </TabItem>
  <TabItem label="React Native">
    ```bash
    npm install zulip-embed-react-native
    ```
  </TabItem>
  <TabItem label="Flutter">
    ```yaml
    # pubspec.yaml
    dependencies:
      zulip_embed: ^1.0.0
    ```
  </TabItem>
</Tabs>

## Pick your framework

<Tabs syncKey="framework">
  <TabItem label="HTML">
    ```html
    <script
      type="module"
      src="https://cdn.jsdelivr.net/npm/zulip-embed@1/dist/zulip-embed.js"
    ></script>

    <zulip-chat
      server="https://chat.example.com"
      auth-token="<short-lived JWT>"
      channel="general"
      topic="welcome"
      theme="light"
    ></zulip-chat>
    ```
    [Full HTML / CDN guide →](/frameworks/html/)
  </TabItem>
  <TabItem label="React">
    ```tsx
    import {ZulipChat} from "zulip-embed-react";

    export function Support() {
      return (
        <ZulipChat
          server="https://chat.example.com"
          authToken={authToken}
          channel="support"
          topic="new"
          theme="light"
        />
      );
    }
    ```
    [Full React guide →](/frameworks/react/)
  </TabItem>
  <TabItem label="React Native">
    ```tsx
    import {ZulipChat} from "zulip-embed-react-native";

    export function SupportScreen({authToken}) {
      return (
        <ZulipChat
          server="https://chat.example.com"
          authToken={authToken}
          channel="support"
        />
      );
    }
    ```
    [Full React Native guide →](/frameworks/react-native/)
  </TabItem>
  <TabItem label="Flutter">
    ```dart
    import 'package:zulip_embed/zulip_embed.dart';

    ZulipChat(
      server: 'https://chat.example.com',
      authToken: authToken,
      scope: const ChannelScope(channel: 'support'),
    )
    ```
    [Full Flutter guide →](/frameworks/flutter/)
  </TabItem>
  <TabItem label="Headless">
    ```ts
    import {ZulipClient} from "zulip-embed";

    const client = new ZulipClient({
      serverUrl: "https://chat.example.com",
      authToken,
      scope: {channel: "support"},
    });
    await client.connect();
    client.subscribe((event) => render(event));
    ```
    [Full headless guide →](/frameworks/headless/)
  </TabItem>
</Tabs>

## Why zulip-embed

<CardGrid>
  <Card title="Framework-agnostic" icon="seti:html">
    Custom elements work in plain HTML, React, Vue, Svelte, Angular,
    Next.js, and any other SSR framework. No build step required for
    the CDN version.
  </Card>
  <Card title="Theme with CSS variables" icon="seti:css">
    Every color, radius, font, and size is a `--zc-*` custom property.
    Match your product's design system without writing a shadow-DOM
    stylesheet. [Theming reference →](/reference/theming/)
  </Card>
  <Card title="Agent-native" icon="seti:graphql">
    Streaming tokens, tool-call messages, and inline confirmation
    widgets land with first-class UI. [Agents reference →](/reference/agents/)
  </Card>
  <Card title="Headless when you need it" icon="seti:typescript">
    Skip the widget and drive the transport directly — build a custom
    UI, power analytics, or integrate with an agent orchestrator.
  </Card>
  <Card title="Open source, Apache-2.0" icon="seti:git">
    Stable v1.0 API under semver. Hosted on
    [GitHub](https://github.com/amanagr/zulip-embed), published to
    [npm](https://www.npmjs.com/package/zulip-embed), installable
    straight from the CDN.
  </Card>
  <Card title="Every Zulip server" icon="seti:default">
    Works against current Zulip and every prior version that ships the
    REST API. The SDK speaks the legacy wire dialect when needed so
    your embed isn't tied to the server's release cadence.
  </Card>
</CardGrid>
