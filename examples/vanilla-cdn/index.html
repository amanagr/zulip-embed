Zulip Embed — vanilla CDN example

This page loads zulip-embed.iife.js from unpkg and mounts a <zulip-chat demo> element below. The demo attribute swaps in an in-memory transport with seeded messages and an echo bot, so nothing talks to a real server.

Running in demo mode — no server required. To connect to a real Zulip server, replace demo with server and auth-token attributes.
