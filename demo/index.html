Installation

Two integration paths:

One-line script tag

<script type="module"
  src="https://unpkg.com/@zulip/embed"></script>

<zulip-chat
  server="https://chat.example.com"
  email="you@example.com"
  api-key="..."
  channel="general"></zulip-chat>

npm package

pnpm add @zulip/embed

// Registers <zulip-chat> on import.
import "@zulip/embed";

// Or use the headless SDK directly:
import {ZulipClient, ZulipTransport} from "@zulip/embed";

Native mobile & desktop

First-class Flutter widgets — no WebView, no JS bridge. Same Zulip REST API, native rendering on iOS, Android, macOS, Windows, Linux, and web.

Flutter demo

The same example app compiled for Flutter web. It ships in the repo at packages/flutter/example/ and runs unmodified on every Flutter target.

Open the Flutter demo → 

flutter pub add zulip_embed

ZulipChat(
