# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text is canonical at that URL — please
read it before participating.

In short: we want this project to be a welcoming space for everyone.
Treat other contributors with respect, assume good faith, and keep
discussion focused on the work.

## Enforcement

Report concerns to **`security@zulip.com`**. This is the same mailbox
we use for security reports — the Zulip maintainers triage conduct
reports alongside security reports. Include a description of what
happened, links or quotes if applicable, and whether you want us to
follow up with you directly.

Reports are handled privately. We acknowledge receipt within 72 hours
and follow up with a decision on next steps. We may ask clarifying
questions; we will not share your identity with the reported party
without your consent except where required by the Covenant's
enforcement steps (e.g., direct warnings).

## Scope

The code of conduct applies everywhere the project operates — issues,
pull requests, discussions, commit messages, code review, and any
project-related chat or event — and to any representative of the
project acting in that capacity in public spaces.

## Attribution

The enforcement approach follows the Contributor Covenant's
[Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines),
which describe the progression from a private warning through to
permanent ban depending on severity and pattern.
